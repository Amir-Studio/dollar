# دولار — مرجع قیمت طلا و ارز

وب‌سایت واکنش‌گرا برای بررسی داده‌های مرجع طلا و ارز؛ زبان پیش‌فرض فارسی است و از بخش بالای صفحه می‌توان به انگلیسی تغییر داد. برند این محصول «دولار» است. امیر استودیو در صفحه راه‌های ارتباطی به‌عنوان توسعه‌دهنده و پشتیبان معرفی شده است.

## تحلیل خبری رایگان و تحلیل هوش مصنوعی اختیاری
- مسیر `/analysis?asset=USD_IRR_FREE` در `worker/` بدون کلید مدل زبانی کار می‌کند: قیمت مرجع و تاریخچه را اعتبارسنجی می‌کند، چند جست‌وجوی Google News RSS فارسی و انگلیسی را می‌خواند، خبرهای دارای تاریخ در ۷۲ ساعت اخیر را با لینک و ناشر برمی‌گرداند و موضوعات خبری را دسته‌بندی می‌کند.
- سناریوی رایگان فقط یک برآورد آماری بر پایهٔ تاریخچه است؛ خبرها به‌صورت موضوعی نمایش داده می‌شوند و اثر مثبت یا منفی خودکار به آن‌ها نسبت داده نمی‌شود. این حالت «هوش مصنوعی مولد» نیست و نباید با آن اشتباه گرفته شود.
- مسیر `/forecast?asset=USD_IRR_FREE` حالت پیشرفتهٔ قبلی را نگه می‌دارد و فقط وقتی `OPENAI_API_KEY` به‌صورت Secret در Cloudflare تنظیم شده باشد، تحلیل مدل زبانی و جست‌وجوی وب را اجرا می‌کند. این قابلیت ممکن است هزینه API داشته باشد و برای حالت بودجه صفر لازم نیست.
- صفحهٔ سایت قیمت‌ها را هنگام باز بودن مرورگر تقریباً هر ۵ دقیقه از منبع عمومی دریافت می‌کند. گزارش رایگان خبر و تحلیل هنگام درخواست کاربر تازه‌سازی می‌شود؛ هنوز زمان‌بندی پس‌زمینه و ذخیرهٔ دائمی خبرها فعال نشده است.
- برای به‌روزرسانی پس‌زمینه حتی وقتی سایت باز نیست، مرحلهٔ بعدی به Cron Trigger و KV namespace در Cloudflare نیاز دارد. شناسهٔ KV باید از حساب Cloudflare خودت ساخته شود؛ هیچ شناسه یا Secret ساختگی در مخزن قرار نمی‌دهیم.
- برای فعال‌سازی Worker، در Cloudflare یک API token با دسترسی Workers و Account ID بساز و در GitHub مسیر **Settings → Secrets and variables → Actions** مقادیر `CLOUDFLARE_API_TOKEN` و `CLOUDFLARE_ACCOUNT_ID` را اضافه کن. سپس workflow انتشار را اجرا کن. در صورت استفاده از مدل پولی، `OPENAI_API_KEY` را فقط در Cloudflare Worker Secrets قرار بده.
- پس از انتشار، نشانی Worker را در بخش «تحلیل داده‌محور بازار → تنظیم اتصال تحلیلگر» سایت ذخیره کن. تا وقتی Worker مستقر و URL آن ذخیره نشده باشد، مرورگر به این endpointها دسترسی ندارد.

## انتشار در GitHub Pages
1. در مخزن، وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و مسیر `/ (root)` را انتخاب و ذخیره کنید.
4. پس از پایان فرایند انتشار، سایت در نشانی `https://amir-studio.github.io/dollar/` در دسترس خواهد بود.

## داده‌ها و محدودیت‌ها
- نرخ‌های مرجع ارز و طلا از فایل عمومی داده‌های Iran Market Data دریافت می‌شوند؛ این داده‌ها به منبع بازار اعلام‌شده توسط پروژه وابسته‌اند و الزاماً قیمت قابل‌معامله در لحظه نیستند.
- نمودار تاریخی از فایل‌های تاریخچهٔ همان منبع بارگیری می‌شود. خط زرد تا زمانی که Worker هوش مصنوعی واقعاً متصل و سالم نباشد، فقط برآورد آماری است و نباید خروجی هوش مصنوعی معرفی شود.
- تحلیل خبری Worker برای قیمت تازه، تاریخچهٔ کافی و کلید معتبر API شرط می‌گذارد؛ اگر شرایط برقرار نباشد باید خطا بدهد، نه اینکه قیمت یا خبر ساختگی بسازد.
- محاسبه‌گر طلا از تبدیل ۳۱٫۱۰۳۴۷۶۸ گرم برای هر اونس تروا و عیار انتخابی استفاده می‌کند؛ اجرت، مالیات، اضافه‌بها و اختلاف قیمت خریدوفروش لحاظ نشده‌اند.
- اگر سرویس یا شبکه در دسترس نباشد، داده ممکن است بارگیری نشود. سایت نباید به‌جای قیمت واقعی، عدد ساختگی نمایش دهد.
