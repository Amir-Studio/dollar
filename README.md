# دولار — مرجع قیمت طلا و ارز

وب‌سایت واکنش‌گرا برای بررسی داده‌های مرجع طلا و ارز؛ زبان پیش‌فرض فارسی است و از بخش بالای صفحه می‌توان به انگلیسی تغییر داد. برند این محصول «دولار» است. امیر استودیو در صفحه راه‌های ارتباطی به‌عنوان توسعه‌دهنده و پشتیبان معرفی شده است.

## تحلیل خبری و پیش‌بینی ۷روزه
کد backend در `worker/` از جست‌وجوی زنده وب برای یافتن خبرهای مرتبط و دارای منبع استفاده می‌کند و نتیجه را با روند آماری تاریخچه ترکیب می‌کند. برای فعال‌سازی باید Worker روی Cloudflare مستقر شود، Secretها تنظیم شوند و URL آن در بخش «تحلیل هوشمند» سایت ذخیره شود. تا پیش از این اتصال، نمودار فقط برآورد آماری نمایش می‌دهد؛ کد عمومی GitHub Pages به‌تنهایی نمی‌تواند کلید امن API را نگه دارد.

## انتشار در GitHub Pages
1. در مخزن، وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment** گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و مسیر `/ (root)` را انتخاب و ذخیره کنید.
4. پس از پایان فرایند انتشار، سایت در نشانی `https://amir-studio.github.io/dollar/` در دسترس خواهد بود.

## داده‌ها و محدودیت‌ها
- نرخ‌های مرجع ارز و طلا از فایل عمومی داده‌های Iran Market Data دریافت می‌شوند؛ این داده‌ها به منبع بازار اعلام‌شده توسط پروژه وابسته‌اند و الزاماً قیمت قابل‌معامله در لحظه نیستند.
- نمودار تاریخی از فایل‌های تاریخچهٔ همان منبع بارگیری می‌شود. خط زرد تا زمانی که Worker هوش مصنوعی واقعاً متصل و سالم نباشد، فقط برآورد آماری است و نباید خروجی هوش مصنوعی معرفی شود.
- تحلیل خبری Worker برای قیمت تازه، تاریخچهٔ کافی و کلید معتبر API شرط می‌گذارد؛ اگر شرایط برقرار نباشد باید خطا بدهد، نه اینکه قیمت یا خبر ساختگی بسازد.
- محاسبه‌گر طلا از تبدیل ۳۱٫۱۰۳۴۷۶۸ گرم برای هر اونس تروا و عیار انتخابی استفاده می‌کند؛ اجرت، مالیات، اضافه‌بها و اختلاف قیمت خریدوفروش لحاظ نشده‌اند.
- اگر سرویس یا شبکه در دسترس نباشد، داده ممکن است بارگیری نشود. سایت نباید به‌جای قیمت واقعی، عدد ساختگی نمایش دهد.

## تبلیغات
