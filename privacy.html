اطلاعیه حریم خصوصی · پیش‌نویس

حریم خصوصی باید روشن و قابل فهم باشد.

این متن پیش‌نویس اولیه برای نسخه فعلی سایت است و تأییدیه حقوقی یا گواهی انطباق محسوب نمی‌شود. سایت در حال حاضر حساب کاربری یا فرم دریافت اطلاعات شخصی ندارد.

سرویس‌های شخص ثالث

سایت برای دریافت داده‌های بازار به سرویس‌های بیرونی متصل می‌شود و ممکن است فونت را از Google Fonts بارگیری کند. این ارائه‌دهندگان ممکن است اطلاعات فنی درخواست، مانند نشانی IP، مرورگر و منبع درخواستی را طبق سیاست‌های خود پردازش کنند.

تبلیغات

در نسخه فعلی فقط جایگاه رزروشده تبلیغ وجود دارد و کد زنده شبکه تبلیغاتی نصب نشده است. پیش از افزودن تبلیغ، آمارگیر یا کوکی، باید نام سرویس‌ها، داده‌های جمع‌آوری‌شده، هدف استفاده، مدت نگهداری و گزینه‌های انتخاب کاربر به این متن افزوده شود.

گزارش‌های میزبانی

GitHub Pages ممکن است داده‌های فنی لازم برای ارائه و ایمن‌سازی سایت را پردازش کند. برای جزئیات، مستندات حریم خصوصی GitHub را بررسی کنید.

تماس و بازبینی

برای پرسش‌های حریم خصوصی از amir0website@gmail.com استفاده کنید. پیش از انتشار تجاری، این متن باید با توجه به محل فعالیت گرداننده سایت، مخاطبان، شرکای تبلیغاتی و قوانین مربوط بازبینی شود.
